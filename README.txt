These are tools for compressing and decompressing files in Sega's "segs" format.

Clownacy originally made these for modding the PS3 version of Sonic Unleashed, so any original resources of the project belongs to him.

The intention is to implement the following additions
- proper ar file conversion of extention files (such as ar.01, 02, 03, etc. rather than just ar.00).
- support of different ar file names
- detection of compressed/decompressed files, and safeguards for those circumstances.
